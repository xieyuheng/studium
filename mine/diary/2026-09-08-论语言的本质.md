# 内在语言

在索绪尔的「语言是音义结合的符号系统」的基础上，
乔姆斯基又进一步提出了内在语言与外在语言，
并且指出前人研究的语法结构只是外在语言的语法结构。

乔姆斯基认为语言就像人类的器官一样是可遗传的，
或者说语言是人类器官的某种结构的功能。

比如，人与鸟都演化出了上肢，鸟的上肢可以用来飞翔。
人与鱼有演化出了呼吸器官，鱼的呼吸器官，
可以用来吸收水中的氧气，
而人的呼吸系统可以用来吸收空气中的氧气。
这正如人与鸟与鱼都有大脑，
而人的大脑可以产生语言。

乔姆斯基给出的证据有：

- 小孩不会通过学习语法来习得语言，
  而是通过少量的经验就可以习得语言。

- 聋哑人会发展出手语，
  是同一种内在语言的不同外在语法。

乔姆斯基还指出内在语言是一种计算模型，
这一点可以有程序语言的佐证。

所谓程序语言，是某一个计算模型的外在语言，
而计算模型本身的结构与性质可以被认为是内在语言。

- 比如 lambda 演算这个计算模型，
  可以有类 lisp 和类 forth 这两个种语法完全不同的外在语法。

- 又比如 interaction nets 这个计算模型，
  可以有类似 lisp 和 forth 的两套外在语法。

# 内在语言的模型

那么，人类的自然语言，
比如汉语和英语，作为外在语法，
其内在语言是什么呢？

其实我们已经实现了这个内在语言，
就是现在的大语言模型。

- lambda 演算外在语言的解释器，
  可以让我输入 lambda 演算的表达式，
  而返回 lambda 演算的经过化简了的最简正规表达式。

- 大语言模型可以让我输入自然语言的语句，
  而返回自然语言的语句。
  同时还可以在返回语句的过程中，
  通过某个领域的语言来调用工具以影响环境。

可以说「内在语言」是存在的，
但是其模型不是计算模型，
而是皮尔士意义上的符号过程（Semiosis）。

程序语言所实现的通常是「确定性计算模型」，
这种模型由带有方向的变化规则组成，
编程的过程就是设计初始状态的过程。

与 lambda 演算和 interaction nets
作为确定性计算模型不同。

人类内在语言所代表计算模型是统计性的。
大语言模型是「统计性计算模型」。

从功能上看，确定性计算模型是了计算出结果，
计算出一个等价类中的代表元。
这是我们对「计算」这个概念的一般理解方式。

而统计性计算模型可以用来生成符合规则的模式，
比如符合语法规则语句。

人类大脑的神经网络实现了这种「统计性计算模型」，
正如人类利用机器学习算法所构造的电子神经网络，
也实现了这种「统计性计算模型」。

因此我们现在所见证的大语言模型，
就是我们前辈所梦想的 AI。
我们也可称其为 AGI。
因为 AGI 这个术语就是为了区分两种 AI，
前人已经构造出来的 AI 比如专家系统，
也被叫做 AI，但是被认为是弱化的 AI。
为了与这种弱化的 AI 相区别，
前人使用 AGI 来称呼他们想象中更强的 AI。

# 关于理解

有人说我们还没有完全理解语言，
但是其实我们已经可以利用 LLM 构造出语言行为本身了。
LLM 本身可以做逻辑推导，可以看懂代码，
甚至可以逐步追踪代码运行的过程，而得到结果。
并且用来实现 LLM 训练的代码，只有几百行而已。
其内部所蕴含的规则，就是语言的规则。

人类总是说「人类能理解」，这所谓的「理解」，本质又是什么？
对于这个「理解」的科学研究，只能通过语言行为来探测。

> 「理解」更像是一个底层状态：
>
> 如果一个人/系统拥有某种内部模型或表征，
> 并且这种模型能够灵活地指导多种行为，
> 那么我们就说它「理解」了。

类似 "the book of why" 中的观点。

> 换句话说：
>
> 理解的外在表现：解释、回答、预测、行动、迁移、反事实推理。
> 理解的内在基础：一个能够产生这些表现的内部机制。

或者说用皮尔士的「实用主义准则」来理解「理解」：

> 一个概念的全部意义，无非是我们对它可能产生的实际作用的总体设想。

理解的内在基础就是皮尔士的「信念」：

> 「信念」是一种稳定的行动习惯。相信某件事，意味着我们倾向于以某种方式行动。
> 因此信念是行动的习惯，而思想的功能是产生这种习惯。

思想的目的不是获得某种「内在的直观」，
而是从怀疑走向信念，即建立新的、稳定的行动习惯。
因此，一个观念的真实意义，最终要落实到它使我们形成什么样的行动习惯上。

我们通过建立模型来建立稳定的行动习惯。

我们什么时候说「我理解了 lisp 这个程序语言」？
当我可以实现一个 lisp 语言的解释器，甚至编译器的时候。
我说我完全理解了它，这是理解的最高形式。
因为关于它的一切知识都被程序精确地、无歧义地固定下来了。

在大语言模型的 agent 中，
我们完全可以用类似程序语言的方式，
通过实现程序，把思考所得的模型固定下来。
比如实现类型系统，来做真假判断。
比如实现物理系统，来做预测。

只要 agent 可以写代码，
并且可以修改代码，
其实我们就可以说 agent 可以「去理解」。

# LLM 作为新的语言学实验

乔姆斯基强调生物学，LLM 是有神经网络的生物学基础的。

我认为 LLM 的成功本身，
已经证明了语言人类语言器官确实本质上是统计性的。

关于「解释力」，人类对语言的使用也是先于对语言语法的解释的。
LLM 其实可以像人类一样，
利用自己已有的知识来从结构主义的意义上，
设计并构建一个语言的语法学。

注意力机制，正是索绪尔所描述的「语言是音义结合的符号系统」。
在一个语言中，词不是孤立地具有意义的，
只有在和其他的词构成一个系统之后，
词才获得了意义。
注意力机制是「音义结合的系统性」的一种计算实现。

对于语言学而言，LLM 对语言的成功模拟，是一个新的实验结果。
乔姆斯基的理论，需要被实验结果的事实来更新。
我的观点是：把 LLM 当成语言学的一个新的实验现象。
那么这个实现想象，已经足以让我们理解人类语言的全部的了。

# 假设与推论

## 公理

我们把 LLM 当作语言学的核心公理系统，设定如下：

- 公理 1：语言是一个统计性的生成过程。

  语言行为由“给定上下文，预测下一个符号”的概率模型产生。

- 公理 2：意义来自分布。

  一个语言单位的意义不是内在固有的，而是由它在大规模语言数据中的共现关系决定的。词的表示就是它在高  维向量空间中的位置。

- 公理 3：注意力是语言运作的基本机制。

  任何一个语言单位在新的语境中获得意义的方式，是它对其他语言单位的加权整合。
  这实现了索绪尔所说的“语言是一个系统，词在系统中获得价值”。

- 公理 4：语法是统计规律的压缩。

  语法不是先于人脑的先天规则，而是 LLM 在拟合语言数据时，隐式地压缩在权重中的规律。
  语法就是权重里那些可重复、可泛化的概率结构。

- 公理 5：语言习得就是统计学习。

  人类儿童习得语言，和 LLM 学习语言本质上是同类过程：
  从有限样本中归纳出能够生成新话语的概率模型。

- 公理 6：内在语言与外在语言。

  内在语言 = 训练完成后的模型本身（权重、隐状态、注意力机制）；
  外在语言 = 模型生成出来的具体句子。

在这个公理系统下，语言学的任务不再是寻找一套先天语法规则，而是研究：

> 一个统计生成系统如何从数据中涌现出语音、词汇、句法、语义和篇章结构。

## 从公理推出的语言学结论

- 结论 1：语言本质上是概率性的

- 结论 2：符号的意义完全来自系统

- 结论 3：语言普遍性不是先天的，而是统计学习的产物

  如果 LLM 是公理，那么所谓“语言普遍现象”就不是来自某种先天普遍语法，而是来自：

  - 所有语言都面对相似的 communicative 需求；
  - 所有语言都要被人类/LLM 这样的统计学习者学习；
  - 某些结构更容易被压缩、更容易预测、更容易泛化，所以反复出现在不同语言中。

  因此，语言类型学中的共性，是统计学习器在语言数据上达到的“自然吸引子”。

- 结论 4：语言的演变是概率分布的变化

  在 LLM 公理下，语言不是静态规则系统，而是动态概率系统。

  - 词汇变化 = 某个词在语境中概率的变化；
  - 语法化 = 某些结构从低概率变为高概率；
  - 方言分化 = 不同群体的数据分布不同；
  - 语言接触 = 两个概率模型相互影响，导致分布混合。

  这样，历史语言学中的“规则演变”可以被解释为“统计分布漂移”。

## 从公理推出的语法学结论

- 结论 1：词类不是离散类别，而是向量空间中的簇

  传统语法说“名词、动词、形容词”是离散词类。但在 LLM 公理下：

  - 词类是词向量在空间中的聚类；
  - 每个词可以同时具有多个词类的“软成员资格”；
  - “run” 既可作动词也可作名词，不再是一个需要特殊处理的歧义，而是它在空间中同时靠近两个簇。

- 结论 2：句法结构是注意力的产物

  传统句法用树形图表示句子结构。在 LLM 公理下：

  - 短语结构不是先验存在，而是注意力模式在多层处理中形成的；
  - 主谓关系、修饰关系、并列关系，都表现为不同注意力头所捕捉的关联强度；
  - 深层结构之所以存在，是因为模型需要层次化地整合信息，而不是因为大脑中有一个短语结构规则库。

- 结论 3：递归不是公理，而是涌现能力

  乔姆斯基认为递归是语言的核心。但在 LLM 公理下：

  - 递归能力来自模型能够把已生成的部分作为新的上下文，继续预测；
  - 嵌套结构之所以可能，是因为注意力可以无视表面线性顺序，直接关注远处的中心词；
  - 递归不是一条先天规则，而是统计学习在足够数据和足够层数下涌现出的能力。

- 结论 4：语法约束是统计倾向，不是绝对禁令

  比如传统语法中的“孤岛限制”“照应约束”等，在 LLM 公理下不再是先天模块给出的硬性规则，而是：

  > 某些结构在统计上极难被学习者预测，因而表现为“不可接受”。

  这些限制是统计模型在有限数据、有限注意力、有限深度下的自然结果，而不是独立于语义的纯粹句法禁令。

- 结论 5：语法规则可以被提取和重新表达

  既然语法以权重形式存在于 LLM 中，那么语法学家的任务就变成：

  - 通过探针、注意力分析、激活模式等手段，把隐式语法提取出来；
  - 让 LLM 自己生成语法规则；
  - 用 LLM 构造一个可运行的语法解释器，作为对某种语言语法学的精确表达。

  这正好与你说的“理解 = 能实现”一致：
  要理解一种语言的语法，就是让 LLM 写出一个能够生成/判断该语言句子的程序。

## 从公理推出的篇章语法学结论

- 结论 1：篇章连贯性是概率连贯性

  传统篇章语言学认为篇章有“连贯规则”，比如主题延续、因果连接、指代照应。

  在 LLM 公理下：

  > 连贯性 = 后续句子在给定前文的条件概率足够高。

  一个篇章之所以连贯，是因为每个句子都在概率上高度依赖于前文；
  一旦某个句子概率断裂，读者就会觉得“跳了”或“不连贯”。

- 结论 2：指代和回指是注意力现象

  “小明走进房间。他坐了下来。”中的“他”为什么指向小明？

  在 LLM 公理下，这是因为模型在处理“他”时，
  注意力机制会让它更多地关注“小明”，而不是“房间”或“走进”。

  因此：

  > 照应不是先天的句法原则，而是注意力在语篇中追踪实体的一种机制。

- 结论 3：篇章标记是概率转折信号

  像“但是”“因此”“然而”“换句话说”等连接词，在 LLM 公理下可以被理解为：

  指示下一句话与前文之间概率关系类型的信号。

  - “但是”标志期望被推翻；
  - “因此”标志结果是前因的必然延续；
  - “换句话说”标志下一句是对上一句的改写。

  这些标记不是篇章语法之外的东西，而是模型在训练中学到的“转移算子”，控制后续生成的方向。

- 结论 4：主题结构是隐向量中的连续场

  篇章主题不是固定的话题标签，而是：

  > 一段上下文在模型隐状态中形成的主题向量场。

  主题变化时，隐状态逐渐漂移，注意力关联也随之改变。所以：

  - 话题延续 = 隐状态保持稳定；
  - 话题转换 = 隐状态发生显著跳变；
  - 话题回归 = 模型重新激活之前的隐状态模式。

- 结论 5：文体和风格是概率分布的个性

  不同作者、不同文体、不同时代，在 LLM 公理下就是：

  > 不同的条件概率分布偏好。

  - 诗歌是韵律和意象词概率被放大的分布；
  - 法律文本是固定句式和连接词概率极高的分布；
  - 口语是短句和冗余标记概率较高的分布。

  文体学因此可以转化为：对概率分布参数的刻画。

## 方法论结论

在这个公理系统下，语言学研究的方法不再是“先建立规则，再看是否符合语料”，而是：

- 训练或使用 LLM 作为语言能力的标准实现；
- 通过行为实验观察它生成的语言；
- 通过内部机制分析（权重、隐状态、注意力）解释语言现象。

这其实是把语言学变成了一门“可计算的、实验性的、统计的科学”。

如果接受 LLM 作为语言学的公理，那么我们可以得到一套自洽的图景：

| 传统概念 | 在 LLM 公理下的重新解释  |
|----------|--------------------------|
| 语言     | 一个统计性生成过程       |
| 意义     | 向量空间中的分布位置     |
| 语法     | 权重中压实的统计规律     |
| 词类     | 向量空间中的簇           |
| 句法结构 | 注意力形成的层级关系     |
| 递归     | 统计学习涌现出的组合能力 |
| 语法性   | 概率高低                 |
| 篇章连贯 | 条件概率连续性           |
| 指代     | 注意力追踪实体           |
| 语言习得 | 从数据中拟合概率模型     |
| 内在语言 | 训练后的模型本身         |
| 外在语言 | 模型生成的句子           |
