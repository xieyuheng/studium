# 机器学习

> Finding the parameters of a function from a data set
> is known as _learning_.
>
> -- _The Little Learner_

带有模型参数的函数：

- 参数为 `w` 与 `b`。

```
y = w x + b
```

数据集：

```
  x   y
-------
2.0 1.8
1.0 1.2
4.0 4.2
3.0 3.3
```

找到最合适的模型参数为 `w = 1` 与 `b = 0`：

- 具体的寻找方式，我们先不讨论。

```
y = x
```

这就是「从数据集学习模型参数」的一个具体例子。

习得模型参数之后，
对于新输入我们就可以预测其输出。

比如对于 `x = 3.79` 预测 `y = 3.79`。

# 归纳推理

回顾[实用主义](2026-08-30-实用主义.md)哲学中所提到的，
三种推理方式：

演绎（Deduction）：规则 + 情况 → 结果

> 规则/大前提：这袋豆子都是白的。
> 情况/小前提：这些豆子来自这袋。
> 结果/结论：这些豆子是白的。

归纳（Induction）：情况 + 结果 → 规则

> 情况/样本类：这些豆子来自这袋。
> 结果/样本属性：这些豆子反复取样都是白的。
> 规则/结论：这袋豆子大概都是白的。

溯因（Abduction）：结果 + 规则 → 情况

> 结果/观察：这些豆子是白的。
> 规则/知识：这袋豆子都是白的。
> 情况/猜测：这些豆子大概来自这袋。

机器学习就是这三种推理方式中的「归纳推理」。

只是

> 情况 + 结果 → 规则

被推广为了：

> 数据集 → 规则

数据集就是样本：

```
  x   y
-------
2.0 1.8
1.0 1.2
4.0 4.2
3.0 3.3
```

其中每一行的数据就是一个样本，
而一个样本的 `x` 和 `y` 分量，
就是样本的两个属性。

我们想要学习出来的规则，
是样本的这两个属性之间的关系。

规则就是模型。

我们首先**猜测**模型是带有 `w` 和 `b`
这两个模型参数的线性函数：

```
y = w x + b
```

这个猜测是另一个层次的「溯因推理」：

> 结果/观察：数据集画在笛卡尔座标系中像是一条直线。
> 规则/知识：线性函数的图像是一条直线。
> 情况/猜测：数据大概由线性模型加小噪声生成。

然后用某种方式找到 `w` 和 `b`，
就「从数据集学习模型参数」。

机器学习所研究的就是这「某种方式」。

机器学习的探究循环：

- 收集所感兴趣的数据集；
- 溯因：猜测模型（可以完全由模型参数代表）；
- 归纳：用机器学习的方法习得模型参数；
- 演绎：用模型来做预测，并且用统计学方法检验模型的有效性。
