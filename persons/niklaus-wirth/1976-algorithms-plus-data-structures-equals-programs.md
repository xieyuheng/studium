# My Motive

[2026-11-02] 这是 Wirth 最著名的教材之一，
书名直接表达全书中心思想：

> 算法与数据结构不可分割；
> 程序就是算法在特定数据表示上的具体实现。

本书假定读者已有基本编程知识，
使用 Pascal 作为统一记法，强调：

* 数据结构决定可用算法及其复杂度；
* 算法需求反过来决定数据表示；
* 用数学分析比较算法；
* 用逐步精化构造较大、可实际运行的程序；
* 通过完整 Pascal 程序展示工程化的程序设计风格。
