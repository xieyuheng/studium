# My Motive

[2026-11-02] 更系统地教学 stepwise 方法的教科书。

其中第 15 章 "stepwise program development"，
是全书方法论的高潮：介绍自顶向下精化与自底向上方法，
并用四个较大的案例展示完整开发过程：

* Gauss 消元法解线性方程组；
* 寻找最小“两种立方和表示”的数，得到 (1729=10^3+9^3=12^3+1^3)；
* 生成前 (n) 个素数；
* 用回溯法生成不含相邻重复子序列的串。

该章强调：程序要经过反复分解、局部验证、效率分析和结构改进。
